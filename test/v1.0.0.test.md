### TC001: 用户首次登录
**目的**：测试新用户首次登录小程序

**前置条件**：小程序已配置云开发环境，用户未使用过小程序

**执行步骤**：

2. 允许微信授权登录
3. 查看个人中心，确认用户信息显示正常

**预期结果**：
- 用户信息正确显示（昵称、头像）

## 测试数据清理

执行完所有测试用例后，执行以下清理操作：

### 清理脚本（云函数或手动执行）

```javascript
// 在微信开发者工具云开发控制台中执行
const db = wx.cloud.database();
const _ = db.command;

// 1. 删除测试创建的 items
db.collection('items').where({
  name: _.or([
    /^测试/,
    /^测试每日事项/,
    /^测试每周事项/,
    /^测试每月事项/
  ])
}).remove();

// 2. 删除测试创建的 checkins（关联测试事项）
db.collection('checkins').where({
  itemId: _.or([
    // 填入上面记录的 itemId
  ])
}).remove();

// 3. 删除测试成员（members 集合中）
db.collection('members').where({
  nickName: /测试用户/
}).remove();

// 4. 删除测试用户（如切换账号测试产生）
db.collection('users').where({
  nickName: _.or([
    /测试用户B/,
    /测试用户C/
  ])
}).remove();

console.log('测试数据清理完成');
```

### 手动清理步骤

1. **登录微信开发者工具**
2. **打开云开发控制台**
3. **删除 items 集合中名称包含"测试"的记录**
4. **删除 checkins 集合中测试创建的记录**
5. **删除 members 集合中测试创建的记录（如有）**
6. **删除 users 集合中测试创建的记录（如切换账号测试）**
